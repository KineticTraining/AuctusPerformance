# Peak Playbook Coach

Build me a modern, clean web application for a sports training membership platform. It needs a landing page explaining the mission, a user registration and login system, a dashboard for members with video library sections, a dedicated page for sports science articles, and a page with a form where athletes can submit video links and notes for coach feedback. Use a sleek athletic design with dark mode styling.
